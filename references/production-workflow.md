# 條漫規劃與分鏡工作流

## 1. 建立單話戲劇任務

先寫四句：

- 主角此刻想要什麼？
- 什麼阻止他？
- 本話哪一刻改變局面？
- 結尾留下什麼新問題？

若四句無法成立，先修故事，不急著拆格。

## 2. 分成節拍而非直接數格

預設節拍可為：

1. 定位：場所、時間、人物當前狀態
2. 日常：建立行為與關係
3. 異樣：出現不協調訊息或目光
4. 加壓：選擇變少、代價升高
5. 轉折：關鍵人物、事件或真相介入
6. 爆點：不可逆行動或情緒突破
7. 餘波：旁人、主角與環境反應
8. 鉤子：下一話必須回答的新問題

每個節拍依情緒需要拆成 1–5 格，不固定格數。使用者要求「超長」時，增加有效節拍、反應與空間過渡，不以重複台詞灌水。

## 3. 逐格規格

每格至少標示：

| 欄位 | 內容 |
| --- | --- |
| 格號／段落 | 方便後續修正與重排 |
| 畫幅 | 小格、中格、橫幅、長直格、滿寬主視覺、無框過場 |
| 鏡位 | 遠景、中景、近景、特寫、俯視、仰視、背影等 |
| 畫面 | 場景、人物位置與關鍵物件 |
| 動作 | 可連接前後格的具體動作 |
| 情緒 | 眼神、嘴角、肩頸、呼吸、距離等可見表現 |
| 文字 | 說話者、台詞／心聲／旁白／擬聲；沒有就標「無」 |
| 版面 | 左右錯落、留白長度、氣泡位置、轉場方式 |

## 4. 對話連戲

- 逐句回答「為什麼此人現在說這句」。沒有動機就刪除或改寫。
- 對話要回應上一句，或刻意迴避上一句；不可無因跳題。
- 自然口語優先於解說式句子。例如質疑工作是否算數時，用「我的工作也可以算嗎？」一類直接反應，不寫生硬繞句。
- 心聲只保留角色不能說出口、且會改變讀者理解的內容。
- 同一資訊不在旁白、心聲與對話中重複三次。

## 5. 角色與空間阻擋

分鏡前先建立簡單狀態表：

- 每位角色的位置、朝向、手部占用、視線與上一動作。
- 關鍵道具的外型、持有人、所在位置與狀態。
- 場景出入口、桌椅、窗戶、光源與可移動路徑。

每一格只允許由前一格可合理到達的狀態。需要跳時或轉場時，用空鏡、字幕或明確場景變化表示。

## 6. 系列連載

- 每話開頭承接上一話最後的情緒或因果，不把角色重置。
- 每話至少推進一項：人物關係、外部目標、謎團、能力、代價或世界觀。
- 保留伏筆清單：已埋、已提示、已回收、尚未回收。
- 續話前摘要上一話新增的硬事實，避免角色、杯子、服裝、筆跡、時間與傷勢漂移。

## 7. 交付控制

- 使用者要求第 N 話圖片時，交付可見成果後才進入第 N+1 話。
- 使用者指出成品缺失、連結不可見或上一話尚未生成時，立即停止後續話數並補齊缺件。
- 使用者只說「繼續」時，接續最近一個已確認節點；若前一輪仍有明確未完成項目，優先完成它。
