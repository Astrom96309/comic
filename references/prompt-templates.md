# 生圖與修正提示詞模板

只有在需要撰寫提示詞或直接製作圖片時讀取。依使用者指定的平台調整語法，不把模板當成不可改的咒語。

## 單話生成主模板

```text
創作一篇原創、可手機向下閱讀的電影感直式 Webtoon 條漫。

本話不可逆事件：{一句話}
故事節拍：{定位／異樣／加壓／轉折／爆點／餘波／鉤子}

角色鎖定：
- {角色A：臉型、五官、髮型、身形、年齡感、服裝、標誌物、氣質}
- {角色B：同上}

場景與空間：
{時間、地點、出入口、關鍵家具、人物起始站位、光源、天氣}

畫面語言：
- 高完成度現代 Webtoon，上色細膩，電影式光影與景深。
- 使用遠景、中景、近景、表情／手部／物件特寫、空鏡與大型高潮長格。
- 面板寬窄與左右位置錯落，利用垂直留白控制時間；閱讀順序清楚。
- 日常段自然低飽和；情緒升高時才提高對比、陰影與局部色偏。
- 人物、服裝、道具、空間、光源與動作跨格一致。

文字布局：
- 對話框靠近正確說話者的嘴部或視線方向，使用畫面負空間。
- 不遮擋臉、眼神、手勢與關鍵道具；只有情緒突破時可刻意侵入主畫面。
- 台詞簡短自然，刪除不推動故事或人物的心聲。
- 繁體中文不得鏡像、反向或亂碼；若無法可靠排字，先生成無字底圖，再於後製加入文字。

逐格內容：
{貼上已確認的逐格分鏡}

禁止：角色變臉、服裝或道具漂移、斷裂肢體、多餘手指、不可能動作、錯誤視線、氣泡遮臉、均勻網格、連續平視對話、海報式拼貼、過飽和、Q版、鏡像文字、照抄參考作品。
```

## 單格修正模板

```text
只修改指定問題，保留其他已確認內容不變。

原圖中需保留：{角色外型、構圖、色彩、背景、其他正確元素}
問題：{可觀察的錯誤}
修正後必須：{可驗證條件}
相鄰格連續性：{前格狀態 → 本格動作 → 後格結果}
文字與氣泡：{正確說話者、完整台詞、位置、不得遮擋處}

不要新增角色、手臂、道具、台詞或劇情；不要改變未指定的臉、服裝、畫風與鏡位。
```

## 角色一致性鎖定片段

```text
將角色參考視為硬約束：保持相同臉型、五官比例、髮型輪廓、髮色、瞳色、年齡感、體型、身高差、服裝剪裁、材質與標誌物。允許表情、姿勢與鏡位改變，但不得因此換臉、換髮型、換服裝或改變身形。
```

## 版面與氣泡鎖定片段

```text
採手機直式長卷閱讀。面板尺寸不均、左右錯落、遠中近特寫交錯，以白色縱向留白控制停頓。對話框靠近說話者嘴部或視線方向，使用負空間，不壓臉、不遮手勢與關鍵道具。只有情緒突破時允許氣泡或字效刻意侵入主畫面。
```

## 負向限制

```text
inconsistent face, costume drift, prop drift, broken hands, extra fingers,
impossible anatomy, wrong eyeline, speech bubble covering face, mirrored text,
garbled Chinese, flat grid layout, repetitive eye-level shot, poster collage,
random background, chibi, childish cartoon, oversaturated color,
copied character, copied panel, copied dialogue
```
