# 電影感直式條漫導演

`create-cinematic-webtoon` 是一個用於創作原創韓系電影感直式 Webtoon 的 Codex Skill。

它把故事概念、角色設定與分鏡需求，轉換成可閱讀、可連載、可生成、可修正的手機長條漫畫流程。核心不是製作單張漂亮插圖，而是讓鏡頭、留白、台詞、動作、空間與情緒一起推動故事。

## 快速開始

在 Codex 或 ChatGPT 中直接呼叫：

```text
使用 $create-cinematic-webtoon，幫我把這個故事做成第一話的超長直式條漫。
```

也可以指定工作內容：

```text
使用 $create-cinematic-webtoon，先幫我做角色設定與第一話逐格分鏡。
```

```text
使用 $create-cinematic-webtoon，檢查這一話的手部、道具、台詞連戲與對話框位置。
```

Skill 的根目錄就是本專案根目錄，至少要保留 `SKILL.md`、`agents/openai.yaml` 與 `references/`。

## 五種工作模式

| 模式 | 適用情境 | 主要交付 |
| --- | --- | --- |
| 規劃 | 只有主題、世界觀或故事概念 | 主線、角色動機、單話目標、轉折與懸念 |
| 分鏡 | 已有劇情或台詞 | 逐格畫幅、鏡位、動作、表情、文字、留白與轉場 |
| 製作 | 要求生成漫畫或畫面 | 已驗算分鏡、完整生圖提示詞或實際圖像產出 |
| 修正 | 已有圖片或使用者指出問題 | 問題診斷、最小充分修改、修正版提示詞 |
| 系列統籌 | 需要持續製作多話 | 世界觀、角色、服裝、道具、時間線與伏筆連續性 |

## 建議使用流程

1. 先說明故事主題、場景、角色與本話不可逆事件。
2. 先建立角色基準與單話節拍，再拆成逐格分鏡。
3. 確認人物站位、手部占用、道具、台詞說話者與氣泡位置。
4. 再要求輸出生圖提示詞或直接製作畫面。
5. 生成後逐點指出問題，例如「杯子不一致」、「氣泡壓到臉」、「台詞接不起來」或「分鏡太平」。
6. 續話時保留上一話硬事實，先完成前一話可見成果，再進入下一話。

## 建議的任務提示格式

```text
使用 $create-cinematic-webtoon。

工作模式：規劃／分鏡／製作／修正／系列統籌
話數：第 {N} 話
故事主題：{一句話}
本話不可逆事件：{本話結束後，什麼事情已經不能回到原狀？}
場景：{時間、地點、天氣、空間配置}
角色：
- {角色 A：外型、服裝、性格、當下狀態}
- {角色 B：外型、服裝、性格、當下狀態}
關鍵道具：{外型、材質、顏色、持有人與位置}
已確認的上一話狀態：{人物、物件、傷勢、情緒與未回收伏筆}
特殊要求：{台詞、鏡位、色調、高潮、懸念或需要避免的問題}
```

## 主要創作規則

### 直式閱讀與電影鏡頭

- 使用遠景建立世界，中景交代站位，近景捕捉互動，特寫放大眼神、手部、物件與呼吸。
- 面板寬窄與左右位置要有變化，避免平均九宮格與連續平視對話。
- 使用白色縱向留白、空鏡與靜止格控制時間；高潮前蓄壓，高潮後安排反應或餘波。
- 低飽和與柔和光影作為日常基調；危機或心理突破才使用強陰影、背景抽離、速度線或局部色偏。

### 角色、動作與空間

- 臉型、五官、髮型、身形、服裝、飾品與氣質要跨格一致。
- 角色不可瞬移；門、桌椅、杯子、手機等反覆出現的道具要保持形狀、方向、材質與位置邏輯。
- 手部與身體動作要符合人體與物理：雙手已拿物時，不可同時做另一個需要手的動作。
- 書寫方向、抓握、視線、光源與陰影必須合理。

### 對話框與文字

- 氣泡靠近正確說話者的嘴部、視線方向或格外負空間。
- 氣泡不得遮住臉、眼神、手勢與關鍵道具，除非情緒突破刻意需要侵入畫面。
- 台詞要自然、互相接得起來；無法推動劇情、人物或氣氛的心聲應刪除。
- 圖像模型常無法穩定生成繁體中文，因此可先生成無字底圖，再把文字放在後製層；文字不可鏡像、反向或亂碼。

### 原創與參考圖

可以參考其他作品的抽象視覺方法，例如長條留白、鏡位切換、情緒節拍與文字布局；不得複製其角色、服裝、場景配置、標誌性分鏡、劇情、台詞或線條。每次都要重新設計人物、事件與畫面細節。

## 最小可用範例

```text
使用 $create-cinematic-webtoon，做一話 40 格左右的直式條漫。

主題：失意的青年在凌晨茶館遇見一位不可能出現的老人。
要求：韓系電影感、低飽和、長留白、左右錯落、泡茶動作取代站樁對話。
角色一致：黑髮青年穿灰色帽T；老人穿深色舊外套；裂紋茶杯每格外型與方向一致。
文字：對話框靠近嘴巴，不遮人物；不需要的心聲刪除；繁體中文不要鏡像。
結尾：老人消失，只留下杯子，杯中浮出一段叫出主角名字的記憶。
```

## 版本與貢獻

修改 Skill 時，請同步更新 `SKILL.md` 與受影響的 `references/`，並在提交前確認：角色連續性、對話連戲、道具一致性、氣泡遮擋、中文方向與長條閱讀節奏都沒有退化。
